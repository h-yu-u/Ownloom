## 可审计基线

本次文档整合核对的源码基线为 [`437f05ba16b89c9d40d23fb0c67fdec5b2c9b953`](https://github.com/h-yu-u/MlxDesktop/tree/437f05ba16b89c9d40d23fb0c67fdec5b2c9b953)。下方“已有记录”来自该版本随仓库保存的维护者描述；原始本机报告、截图和模型未纳入 Git，不能从此仓库重新打开验证。整理文档不会自动重跑或继承这些结果。

新增结论须注明 commit、环境、实际命令、模型身份/revision、应用摘要及可访问的结果位置。当前 PR 的执行结果以 PR/CI 记录为准，没有结果的项目保持未验证。测试文件数量或历史测试总数不能当作最新通过证据。

## 首次自动化发布

2026-10-28 首次以预览形式发布的 [v0.1.0](https://github.com/h-yu-u/Ownloom/releases/tag/v0.1.0)对应源码 [`f4f90b7`](https://github.com/h-yu-u/Ownloom/commit/f4f90b7062ddb788bf89918bb4cbec38eeea03fc)。[云端运行记录](https://github.com/h-yu-u/Ownloom/actions/runs/40552314234)包含 Ubuntu 版本校验、GitHub 托管 macOS ARM 的源码/测试/Rust 检查、完整应用构建及最终 DMG 内两轮隔离 smoke。首次发布在新草稿的列表回读处中止，复用已验收制品重跑发布任务后成功；后续发布器改用创建响应，并有对应回归测试。

公开制品 `Ownloom_0.1.0_aarch64.dmg` 为 449841100 字节，SHA-256 为 `a1ea1d2db91df4ca189ed82151366bd8438c15739c37e96f9221f0ead06b6e21`。[公开元数据](https://github.com/h-yu-u/Ownloom/releases/download/v0.1.0/release-metadata.json)绑定源码、签名性质和 smoke 范围。该制品使用 ad-hoc 签名，未公证；真实模型、原生 GUI/Gatekeeper、独立干净机器及长期稳定性不在此运行结论内。

## 记录与更新规则

功能变化更新[对应子系统](./subsystems/README.md)，方法更新[发布验收](./release-acceptance.md)。本页只保留支持声明所需的当前结果、证据位置和未解决缺口。

结果区分 `passed`、`failed`、`interrupted`、`not_run` 及需审查警告。模型结果绑定资源身份，包内结果绑定清单摘要；更换源码、应用资源或模型后，只能继承明确未受影响的证据，并说明判断依据。

原始数据库、模型、录音、凭据和私有诊断不提交 Git。公开报告先脱敏，放入可访问的 CI artifact 或发布附件并链接；只在维护者电脑上的 `.build/` 路径不能作为公开证据链接。
