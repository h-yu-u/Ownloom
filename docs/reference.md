# Ownloom 使用手册

[文档入口](./README.md) · [开发环境](./development.md) · [验证范围](./verification.md)

Ownloom 是面向 Apple Silicon macOS 的本地 AI 工作台。聊天、Coding、图片创作和语音创作使用本机模型，模型库集中管理下载和导入；可选联网搜索与 MCP 服务按照配置访问外部服务。

## 开始使用

1. 按[开发环境](./development.md)从源码启动。当前仓库未提供已发布的安装包。
2. 打开“模型库”，导入完整本地模型目录，或通过“发现模型”选择 Hugging Face 仓库下载。
3. 进入相应工作区，选择具备该能力的模型并提交任务。正常应用的初始模型库为空，不自动添加模拟模型。
4. 在主导航末尾的任务中心查看进行中、待批准及已结束任务，或返回原工作区查看结果。

首次安装依赖和下载模型需要网络。模型能否运行取决于导出结构、引擎版本、可用内存和所需能力；下载成功与扫描通过均不代表已经完成真实推理验收。

## 模型库

发现目录查询 Hugging Face 的公开 MLX 元数据，支持名称搜索。已有模型可导入包含配置、分词器及完整权重的目录；分片权重必须齐全。应选择实际导出目录，不能仅凭仓库名称选择父目录。

下载可暂停、恢复或取消。应用重启后，未完成下载显示为暂停，需要手动恢复。下载模型默认保存到 `~/MLXModels`，可通过启动 Runtime 时的 `MLX_STUDIO_MODELS_DIR` 指定目录。

“移除登记”与“删除文件”是独立操作：导入目录只移除登记；托管下载只有满足目录所有权和引用保护条件才可删除文件。模型被活动任务使用时应先停止任务或等待完成。实现与兼容性维护见[模型子系统](./subsystems/models.md)。

## 聊天、附件与联网搜索

选择文本模型后输入问题，首次发送会准备模型。Enter 发送，Shift+Enter 换行，中文输入法确认不应触发发送。生成时可以停止或浏览其他会话。失败保留当前草稿和附件，已保存的成功回答不会因一次失败的重新生成而被覆盖。

回答长度默认“自动最大”，根据模型窗口中输入、历史和资料占用后的空间分配输出预算；它是上限，不要求模型填满。手动模式范围随模型窗口变化。只有最后一条因输出上限截断的回答提供“继续回答”。

附件入口支持选择、拖入和粘贴：

| 类型                 | 当前处理方式                                               |
| -------------------- | ---------------------------------------------------------- |
| PNG、JPEG、WebP、GIF | 图片预览和模型视觉输入；GIF 取首帧，图片数量受模型能力限制 |
| UTF-8 TXT、Markdown  | 提取文字并按问题选择上下文                                 |
| DOCX                 | 提取正文与常见表格                                         |
| 有文本层的 PDF       | 提取文字并保留页码；扫描页不执行 OCR                       |

每条消息最多 8 个附件，单文件最多 20 MiB，总大小最多 60 MiB。等附件准备完成后再发送，点击附件可查看实际提取内容。部分页面不可读时会明确提示；超出预算的全文总结不会用局部片段代替全文。

联网默认关闭。在“设置 → 扩展能力 → 内置工具”配置 Tavily 兼容服务地址和 API Key，保存后测试连接，再在聊天输入区开启联网。查询会发送到所配置的服务，附件解析在本机进行。来源区域区分网页正文摘录与仅搜索摘要，网页链接交给系统浏览器打开。没有可用来源时显示失败，不把模型记忆当作实时检索结果。

会话支持重命名、删除及置顶。侧栏搜索过滤已载入的列表，不承诺跨全部历史的全文搜索。详细行为、资料预算及来源保存见[聊天子系统](./subsystems/chat.md)。

## 图片创作

选择模型和模式，填写提示词及参数，提交后查看任务阶段和进度。聊天、图片、语音及 Coding 的本地推理共享资源，忙碌时需要等待。切换页面不会取消已接纳的生成任务。

- **文字生图：** 设置比例或尺寸、步数及 Seed；不指定 Seed 时使用随机值。
- **图片编辑：** 选择支持编辑的完整模型，上传原图与参考图。最多 10 张 PNG/JPEG/WebP，每张最多 20 MiB；图 1 是原图，其余顺序与提示词中的编号对应。
- **局部重绘：** 涂抹要修改的区域，支持画笔、橡皮擦、撤销和清空。替换原图后需重新指定区域。

作品历史提供预览、原图对比、PNG 导出、继续编辑和参数复用。缺失模型、参考图或蒙版时会提示，不能静默换用另一份资源。中断任务保留可复用参数，但不会跨重启续算。

## 语音创作

Qwen3-TTS CustomVoice 模型用于预设音色合成，Base 模型用于参考克隆。选择相应模式、模型和音色，输入朗读文本后生成；单次文本最多 2000 字。

参考音色需要 16 位 PCM WAV，采样率 8–96 kHz、单声道或双声道、时长 0.1–30 秒、文件最多 12 MiB。填写准确参考原文、语言、名称和素材来源，并确认拥有声音使用权。建议选择单人、低噪声的短录音。

作品支持试听、暂停、波形、参数复用及 WAV 导出。“停止播放”只控制播放器，“取消生成”控制后台任务。当前未提供录音、自动转写、实时音频流或声音设计。图片和音频的维护细节见[媒体子系统](./subsystems/media.md)。

## Coding、Skills 与 MCP

在 Coding 中选择本地项目和模型，创建会话后描述任务。使用界面显示的访问模式，并逐次查看需要批准的命令、受保护修改或工具操作。右侧“变更”和“文件”用于检查受管差异及项目文件；执行过命令与验证已经通过是不同状态，以界面保存的验证证据为准。

Skills、MCP 服务和内置工具在“设置 → 扩展能力”维护。启用配置不等于授予所有调用权限，调用仍受绑定范围和审批约束。普通聊天默认不调用工作区扩展。模型工具协议能力需要实际验证，不能仅按模型名称认定。具体维护见 [Coding](./subsystems/coding.md) 与[扩展子系统](./subsystems/extensions.md)。

## 设置、任务与故障恢复

设置包括 Coding 默认值、扩展能力、运行与诊断、隐私与数据。未保存的设置与已保存值分别显示，连接测试针对已保存版本。草稿只在当前应用进程中保留，不承诺退出后恢复。

任务中心按会话归并任务，显示实际标题、工作区、当前状态和待批准提示。读取失败可以重试；旧缓存可能继续显示，但不会被解释为最新状态。页面离开只释放观察资源，停止任务需使用对应操作。

Runtime 失联时先查看运行状态与错误，再使用界面提供的重启入口。重启不会继续执行未完成的生成或重放批准过的命令，历史结果仍由持久化数据恢复。问题反馈应包含应用版本、平台、模型及错误码，先检查诊断内容再分享。

## 数据位置与备份

下列名称是实际技术标识，应按原样使用：

| 数据           | 当前位置或所有者                                            |
| -------------- | ----------------------------------------------------------- |
| 桌面资料库     | Tauri `app_data_dir()`；应用标识 `local.mlxstudio.app`      |
| 主数据库       | 当前资料库的 `app.db`                                       |
| Coding 数据    | 主数据库所在目录的 `coding/`，包含 Node Host 数据与 Pi 会话 |
| 图片与音频     | 对应媒体目录的 `images/`、`audio/`                          |
| 附件与派生内容 | 同一媒体目录中的受管附件资源                                |
| 模型权重       | 默认 `~/MLXModels`，或导入时选择的外部目录                  |
| 搜索/MCP 凭据  | macOS Keychain，不写入普通备份                              |

桌面壳通过 `MLX_STUDIO_DATA_DIR` 传递资料库位置。独立 Runtime 未指定它时使用 `~/Library/Application Support/MLX Studio/data/app.db`，媒体位于 `~/Library/Application Support/MLX Studio/media/`。恢复后的资料库可能位于独立 profile；以当前运行配置为准，不要仅备份一个猜测的数据库路径。

在“设置 → 隐私与数据”导出备份，恢复时先查看校验结果，再确认导入独立资料库；重启生效，原资料库保留并可撤销切换。模型权重和 Keychain 凭据不包含在备份中，另一台机器可能需要重新配置模型路径和凭据。

自动附件清理默认关闭。显式清理会再次核对历史、任务、草稿及其他引用，把可清理项移入回收站。数据所有权、保护和恢复规则见[存储子系统](./subsystems/storage.md)。
