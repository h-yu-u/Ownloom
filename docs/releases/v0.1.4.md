## What's new

Changes since v0.1.3:

- Compatible Qwen models can use experimental local draft acceleration: automatic routing selects MTP for ordinary chat and DFlash2 for Coding, or you can select either explicitly. New configurations default to off; existing MTP settings are preserved. Matching draft weights are required separately.
- Eligible ordinary-chat and Coding requests reuse bounded, in-memory context prefixes. Supported Qwen chat checkpoints advance as conversations grow, and long requests can continue reusing a bounded prefix. Cache state is scoped to the conversation and model and is discarded on failure, cancellation or Worker restart.
- Successful chat answers and Coding turns show native generation speed, the actual draft mode, total input tokens, tokens reused from earlier requests and newly processed input. Expanded details include Worker input preparation, first visible text wait and generation duration. Missing measurements stay unknown; these timings exclude queueing, model loading and web preparation.
- Coding uses Pi's native tool-argument correction and an output budget based on the actual remaining context. New files can be created without a prior-content hash; overwriting an existing file still requires the matching hash.

## Fixes and improvements

- Preserve the full attention mask when handing a manually prefilled Coding prefix to MLX-VLM, keeping the remaining tokens at their correct absolute positions. Unsupported input shapes and media markers use the ordinary input path.
- Protect draft settings while a Coding or Agent task is preparing, queued, running tools or waiting for approval. Attempts to change settings explain that the model is still in use, instead of invalidating the next inference call.
- Await MCP connection credentials before submitting a task to the Host, and release temporary model reservations if preparation fails.
- Keep actual cross-request cache reuse separate from prefill performed in the current request, including when an optional snapshot cannot be stored.
- Describe global package installations and custom package scripts accurately in the Coding timeline; the original command and approval remain available.
- Restore type checking in environments without optional MLX inference dependencies and clarify the sampling and validation limits of experimental drafts.

## Installation

**macOS (Apple Silicon):** [ownloom-darwin-arm64.dmg](https://github.com/h-yu-u/Ownloom/releases/download/v0.1.4/ownloom-darwin-arm64.dmg)

Open the DMG and drag **Ownloom.app** into **Applications**. To install the latest published version from Terminal:

```sh
curl -fsSL https://github.com/h-yu-u/Ownloom/releases/latest/download/install.sh | sh
```

Quit Ownloom before updating. Open the app, add a compatible local model in **Models**, then select it in **Chat** or verify its tool support for **Coding**. Model weights are downloaded separately. Draft acceleration is experimental and does not guarantee a speedup or identical output for every model or task.

The app is ad-hoc signed and has not been notarized by Apple. First launch may require approval in **System Settings → Privacy & Security**.

## 新增功能

以下更新相对于 v0.1.3：

- 兼容的 Qwen 模型支持实验性本地草稿加速：自动模式为普通聊天选择 MTP、为 Coding 选择 DFlash2，也可明确指定其中一种。新配置默认关闭，已有 MTP 设置保留；配套草稿权重需另行准备。
- 符合条件的普通聊天与 Coding 请求复用有容量限制的内存上下文前缀。受支持的 Qwen 聊天会随对话增长推进检查点，较长请求也可继续复用有界前缀。缓存按会话与模型隔离，失败、取消或 Worker 重启后清除。
- 成功的聊天回答与 Coding 轮次显示原生生成速度、实际草稿方式、输入总 token 数、从先前请求复用的 token 数及本轮新处理的输入。展开后可查看 Worker 内的输入准备、首段可见文字等待和本轮推理耗时。缺失数据保持未知；这些耗时不含排队、模型加载和联网准备。
- Coding 使用 Pi 原生工具参数纠错，并按实际剩余上下文计算输出预算。新建文件可省略原内容哈希，覆盖已有文件仍需匹配哈希。

## 修复与改进

- 修复 Coding 手工预填充前缀交给 MLX-VLM 时丢失完整注意力掩码的问题，保留剩余 token 的正确绝对位置。不支持的输入形状或媒体标记走普通输入路径。
- Coding 或 Agent 任务处于准备、排队、工具执行或等待审批阶段时，保护其使用中的草稿设置。尝试更改时明确提示模型仍在使用，避免下一次推理因模型身份变化失败。
- 任务提交给 Host 前正确等待 MCP 连接凭据读取；准备失败时释放临时模型引用。
- 统计区分跨请求实际复用量与本轮预填充，即使可选缓存快照保存失败也保持正确口径。
- Coding 时间线准确区分全局安装和自定义包脚本；原始命令与审批入口保持可查看。
- 修复未安装可选 MLX 推理依赖时的类型检查，并明确实验性草稿的采样方式与验证限制。

## 安装

**macOS（Apple Silicon）：** [ownloom-darwin-arm64.dmg](https://github.com/h-yu-u/Ownloom/releases/download/v0.1.4/ownloom-darwin-arm64.dmg)
