## What's new

- Added a Terminal installer that downloads and checks the Apple Silicon DMG, then installs or replaces Ownloom while preserving models and application data.
- Trimmed unused Runtime modules, test files and Coding development files, including source maps, type declarations and the standalone Pi CLI.
- Renamed the Apple Silicon download to `ownloom-darwin-arm64.dmg`.
- Reworked the quick start around installing the app, opening Ownloom and adding a model. Source setup and development commands now live in the contribution guides.

## Install

**macOS (Apple Silicon):** [ownloom-darwin-arm64.dmg](https://github.com/h-yu-u/Ownloom/releases/download/v0.1.1/ownloom-darwin-arm64.dmg)

Open the DMG and drag **Ownloom.app** to **Applications**. Or install the latest version from Terminal:

```sh
curl -fsSL https://github.com/h-yu-u/Ownloom/releases/latest/download/install.sh | sh
```

Quit Ownloom before updating. Open the app after installation, add a compatible model in **Models**, then select it in **Chat** to get started.

Model weights are downloaded separately. This build is ad-hoc signed and has not been notarized by Apple; the first launch may require approval in **System Settings → Privacy & Security**.

## 安装

**macOS（Apple Silicon）：** [ownloom-darwin-arm64.dmg](https://github.com/h-yu-u/Ownloom/releases/download/v0.1.1/ownloom-darwin-arm64.dmg)

打开 DMG，将 **Ownloom.app** 拖入**应用程序**。也可以通过终端安装最新版：

```sh
curl -fsSL https://github.com/h-yu-u/Ownloom/releases/latest/download/install.sh | sh
```

更新前先退出 Ownloom。安装后打开应用，在**模型库**下载或导入兼容模型，再到**聊天**选择模型并开始使用。

模型权重需另行下载。当前安装包使用 ad-hoc 签名，尚未经过 Apple 公证；首次打开时，可能需要在**系统设置 → 隐私与安全性**中手动允许。
