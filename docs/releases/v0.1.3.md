## What's new

Updates since v0.1.1, the previous public release.

- Ordinary Chat now shows generation speed in tok/s and the output token count reported by MLX-LM or MLX-VLM. The speed is the engine's cumulative average for the current generation.
- Final statistics are saved with successful replies and remain available after reopening the conversation or restarting Ownloom. Replies without native statistics, including older messages, do not show a statistics row.

## Fixes and improvements

- Fixed overlapping chat submissions and late responses affecting a different conversation. Stream recovery now prevents older snapshots from reverting text or duplicating buffered output.
- Prevented older Coding updates from reverting task progress. Equivalent file paths use the same approval checks before managed edits.
- Kept new inference and Coding/Agent tasks from starting while resources from an earlier task have not been released successfully.
- Made backups wait for writes already in progress, including audio uploads and Skill previews, and excluded temporary audio uploads from backups.
- Added cancellation and cleanup for restore previews, and cleaned up temporary backup and restore files after completion, cancellation or failure.
- Prevented an export from opening a delayed save dialog after leaving its page, while preserving the result of a save that has already started.
- Rolled back newly published Skill files when an import fails. Fixed retries of Skill imports or publications on macOS incorrectly rejecting an existing identical version because of temporary-directory path aliases.
- Moved MCP credential I/O off the runtime event loop to avoid blocking that loop during system credential operations.

## Install

**macOS (Apple Silicon):** [ownloom-darwin-arm64.dmg](https://github.com/h-yu-u/Ownloom/releases/download/v0.1.3/ownloom-darwin-arm64.dmg)

Open the DMG and drag **Ownloom.app** to **Applications**. Or install the latest version from Terminal:

```sh
curl -fsSL https://github.com/h-yu-u/Ownloom/releases/latest/download/install.sh | sh
```

Quit Ownloom before updating. Open the app after installation, add a compatible model in **Models**, then select it in **Chat** to get started. Installing from the DMG does not require downloading `release-metadata.json`.

Model weights are downloaded separately. This build is ad-hoc signed and has not been notarized by Apple; the first launch may require approval in **System Settings → Privacy & Security**.

## 新增功能

以下更新相对于上一公开版本 v0.1.1。

- 普通聊天新增生成速度（tok/s）和输出 token 数，直接使用 MLX-LM 或 MLX-VLM 返回的原生统计。生成速度是引擎报告的本次生成累计平均值。
- 最终统计随成功回答保存；重新打开会话或重启 Ownloom 后仍可查看。旧消息及没有原生统计的回答不显示统计行。

## 修复与改进

- 修复聊天并发提交和迟到回复影响其他会话的问题；流式恢复时，旧快照不再导致正文回退或缓冲文字重复显示。
- 修复旧的 Coding 状态更新导致任务进度倒退的问题；指向同一文件的不同路径写法，使用一致的受管编辑审批检查。
- 修复旧任务的资源尚未成功释放时，新的推理或 Coding/Agent 任务仍可能启动的问题。
- 备份会等待已经开始的写入完成，包括音频上传和 Skill 预览产生的暂存写入；临时音频上传不再进入备份。
- 恢复预览支持取消并释放暂存；备份和恢复流程完成、取消或失败后，清理对应的临时文件。
- 修复离开页面后，导出操作仍迟到弹出保存窗口的问题；已经开始的保存继续保留实际结果。
- Skill 导入失败时回滚本次新发布的文件；修复 macOS 上重试 Skill 导入或发布时，已有相同版本可能因临时目录的不同路径写法被错误拒绝的问题。
- MCP 凭据存取移出运行时事件循环，避免同步系统调用阻塞该循环。
