## First release

- Added a local AI desktop app for Apple Silicon Macs, with Chat, Models, Image, Speech and Coding workspaces.
- Find and download compatible MLX models from Hugging Face, or import an existing model folder.

## Install

**macOS (Apple Silicon):** [Ownloom_0.1.0_aarch64.dmg](https://github.com/h-yu-u/Ownloom/releases/download/v0.1.0/Ownloom_0.1.0_aarch64.dmg)

Open the DMG and drag **Ownloom.app** to **Applications**. Open Ownloom, add a model in **Models**, then select it in **Chat** to send your first message. Image, Speech and Coding have their own workspaces and require compatible models.

Model weights are downloaded separately. This build is ad-hoc signed and has not been notarized by Apple; the first launch may require approval in **System Settings → Privacy & Security**.

## 首次发布

- 提供面向 Apple Silicon Mac 的本地 AI 桌面应用，包含聊天、模型库、图片创作、语音创作和 Coding 工作区。
- 在模型库从 Hugging Face 下载兼容的 MLX 模型，或导入已有模型文件夹。

## 安装

**macOS（Apple Silicon）：** [Ownloom_0.1.0_aarch64.dmg](https://github.com/h-yu-u/Ownloom/releases/download/v0.1.0/Ownloom_0.1.0_aarch64.dmg)

打开 DMG，将 **Ownloom.app** 拖入**应用程序**。打开 Ownloom，在**模型库**添加模型，再到**聊天**选择模型并发送第一条消息。图片、语音和 Coding 分别在对应工作区使用，需要选择兼容的模型。

模型权重需另行下载。当前安装包使用 ad-hoc 签名，尚未经过 Apple 公证；首次打开时，可能需要在**系统设置 → 隐私与安全性**中手动允许。
